# Weather App

Приложение прогноза погоды: пользователь вводит город и получает текущую
температуру, ощущаемую температуру, влажность, скорость ветра и описание
погоды. Данные берутся из API OpenWeather.

Вёрстка делается по макету в Figma. Стек — чистые HTML, CSS и JavaScript,
без фреймворков и сборщиков.

## Договорённости по разметке

Это главное соглашение в проекте. HTML и JavaScript пишутся параллельно
разными людьми, поэтому имена классов фиксируются заранее: JavaScript ищет
элементы именно по ним. Если разметка назовёт поле ввода иначе, скрипт его
не найдёт, и выяснится это только при сборке.

Внутреннюю структуру, вложенность и семантику тегов определяет автор
разметки. Обязательны только сами имена классов.

| Класс | Назначение |
| --- | --- |
| `header`, `header-title` | шапка и заголовок |
| `weather-app` | основной контейнер |
| `search-form` | форма поиска |
| `city-input` | поле ввода города, атрибут `name="city"` |
| `search-button` | кнопка отправки, `type="submit"` |
| `loading` | надпись о загрузке |
| `weather-result` | блок с результатом целиком |
| `main-card` | главная карточка |
| `temperature` | температура |
| `city-name` | название города |
| `weather-icon` | иконка погоды, тег `img` |
| `details` | контейнер карточек с деталями |
| `feels-card` | карточка «ощущается как» |
| `detail-title` | подпись внутри карточки |
| `feels-like` | значение ощущаемой температуры |
| `other-card` | карточка с остальными данными |
| `humidity`, `wind`, `description` | влажность, ветер, описание |
| `error-card` | блок ошибки |
| `error-title`, `error-message` | заголовок и текст ошибки |
| `hidden` | утилита: скрывает элемент (`display: none`) |

Блоки `loading`, `weather-result` и `error-card` при загрузке страницы
скрыты — на них сразу стоит класс `hidden`.

Подключение скриптов в `index.html` — строго в таком порядке:

```html
<script src="./config.js" defer></script>
<script src="./index.js" defer></script>
```

`config.js` объявляет константу `APP_ID`, `index.js` её использует.

## Ключ API

Ключ OpenWeather в репозиторий не попадает — репозиторий публичный, и любой
выложенный ключ находят автоматические сканеры за считаные минуты.

Каждый создаёт файл локально:

```bash
cp config.example.js config.js
```

Дальше открываем `config.js` и вставляем свой ключ. Бесплатно он берётся на
<https://openweathermap.org/api>, в разделе «My API keys» после регистрации.
Новый ключ начинает работать не сразу, иногда нужно подождать до часа.

`config.js` перечислен в `.gitignore`, поэтому случайно закоммитить ключ
не получится.

## Как работаем

В `main` напрямую не коммитим — только через Pull Request.

```bash
git switch main
git pull
git switch -c feature/название-задачи
```

Работаем, затем:

```bash
git add .
git commit -m "Короткое описание на английском"
git push -u origin feature/название-задачи
```

После пуша на GitHub появится кнопка «Compare & pull request» — открываем PR
и назначаем ревьюера. Свой PR не мержим сами.

Перед каждой новой веткой обязательно `git pull` в `main`: иначе будешь
работать поверх устаревшего кода. Если `git pull` ничего не тянет — проверь
`git branch -vv`, скорее всего стоишь не на той ветке.
